Formula & Fact Sheets

The identities, theorems and standard results that show up again and again in NMTC problems. Don't just memorise — know one example of each in action.

🔢 Number Theory

  • Sum of first n natural numbers 1 + 2 + … + n = n(n+1)/2
  • Sum of first n odd numbers 1 + 3 + 5 + … + (2n−1) = n²
  • Sum of squares 1² + 2² + … + n² = n(n+1)(2n+1)/6
  • Sum of cubes 1³ + 2³ + … + n³ = [n(n+1)/2]²
  • Number of divisors of N = paqbrc d(N) = (a+1)(b+1)(c+1)
  • HCF × LCM HCF(a, b) × LCM(a, b) = a × b
  • Fermat's little theorem (p prime, p ∤ a) ap−1 ≡ 1 (mod p)
  • Trailing zeros of n! ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + …
  • Units digits of powers cycle with period 1, 2 or 4 — reduce the exponent mod the cycle length
  • For prime p > 3 24 divides p² − 1

🧮 Algebra

  • Basic identities (a ± b)² = a² ± 2ab + b² ; a² − b² = (a−b)(a+b)
  • Cubes a³ ± b³ = (a ± b)(a² ∓ ab + b²)
  • The three-variable classic a³ + b³ + c³ − 3abc = (a+b+c)(a² + b² + c² − ab − bc − ca)
  • …so if a + b + c = 0 a³ + b³ + c³ = 3abc
  • Quadratic x² + px + q = 0 with roots α, β α + β = −p, αβ = q ; α² + β² = (α+β)² − 2αβ
  • Power sums recurrence (roots of x² = sx − q) αⁿ + βⁿ = s(αⁿ⁻¹ + βⁿ⁻¹) − q(αⁿ⁻² + βⁿ⁻²)
  • AM–GM inequality (a, b ≥ 0) (a + b)/2 ≥ √(ab), equality iff a = b
  • Telescoping 1/(n(n+1)) = 1/n − 1/(n+1)
  • Geometric series (|r| < 1) a + ar + ar² + … = a/(1 − r)
  • AP: nth term & sum aₙ = a + (n−1)d ; Sₙ = n(a + aₙ)/2

📐 Geometry

  • Angle sum of an n-gon (n − 2) × 180°
  • Diagonals of an n-gon n(n − 3)/2
  • Pythagoras a² + b² = c² (right angle opposite c)
  • Inradius of a right triangle (legs a, b, hyp c) r = (a + b − c)/2
  • Area of a triangle ½ × base × height = rs = abc/(4R) (r = inradius, s = semi-perimeter, R = circumradius)
  • Heron's formula Area = √(s(s−a)(s−b)(s−c)), s = (a+b+c)/2
  • Chord at distance d from centre, radius r chord length = 2√(r² − d²)
  • Angle in a semicircle 90° ; central angle = 2 × inscribed angle on the same arc
  • Cyclic quadrilateral opposite angles sum to 180°
  • Clock hands hour hand: 0.5°/min ; minute hand: 6°/min ; relative: 5.5°/min

🎲 Combinatorics & Counting

  • Permutations & combinations P(n, r) = n!/(n−r)! ; C(n, r) = n!/(r!(n−r)!)
  • Handshakes / pairs from n people C(n, 2) = n(n−1)/2
  • Subsets of an n-element set 2ⁿ (including ∅) ; sum of all C(n, k) = 2ⁿ
  • Circular arrangements of n people (n − 1)!
  • Inclusion–exclusion (two sets) |A ∪ B| = |A| + |B| − |A ∩ B|
  • Pigeonhole principle n+1 objects in n boxes ⇒ some box holds ≥ 2
  • Binomial theorem (1 + x)ⁿ = Σ C(n, k) xᵏ
  • Squares on an n × n grid 1² + 2² + … + n² = n(n+1)(2n+1)/6

⚡ Contest Tactics

  • Work modulo small numbers. Last-digit and remainder questions almost always reduce to a short repeating cycle.
  • Try small cases first. Compute the pattern for n = 1, 2, 3 and guess the general rule — then justify it.
  • Factor before you expand. Contest algebra rewards recognising a² − b², telescoping, and symmetric functions of roots.
  • Draw and label. In geometry, mark every equal angle and length; the solution usually appears in the picture.
  • Count complements. "At least one" is usually easier as "total minus none".
  • Estimate to eliminate. In the objective round, bounding the answer often kills three options instantly.
